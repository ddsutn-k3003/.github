## 🧭 Sobre el curso

DDSI trabaja el diseño de aplicaciones empresariales: cómo se piensa, se estructura y se hace evolucionar un sistema de información.

Los temas del curso incluyen:

- Modelado y diagramas UML
- Diseño por capas y atributos de calidad
- Arquitectura de software y microservicios
- Integración sincrónica y asincrónica de aplicaciones
- Persistencia relacional, mapeo objeto-relacional y bases NoSQL
- Observabilidad, seguridad y recursos de infraestructura
- Principios y patrones de diseño

A lo largo del año se desarrolla un **Trabajo Práctico Anual (TPA)** con entregas durante la cursada.
